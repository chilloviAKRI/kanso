# Kanso

Kanso — браузер для Omarchy 4.5 на основе Firefox 160.0.1. У него отдельный профиль, компактные горизонтальные вкладки и новая вкладка с одним полем поиска. Браузер автоматически считывает палитру Omarchy, шрифт Fontconfig и обои. Радиус вкладок, адресной строки, меню и панели поиска следует за текущим `decoration:rounding` в Hyprland. Толщина рамок активной вкладки и поля поиска следует за `general:border_size`. Фон новой вкладки сочетает фон и приглушённый акцент темы. Тонкие движущиеся линии из разноцветных пикселей используют палитру текущих обоев, включая кадр видеообоев. При включённом уменьшении движения волны статичные. Стандартное выделение текста использует синий фон и белый текст во всех темах. В обычных окнах при включённой синхронизации Kanso применяет оформление Omarchy, даже если Firefox Sync активирует другую тему. Приватные окна сохраняют своё оформление Firefox. Для совместимости с сайтами Kanso использует стандартный User-Agent своей версии Firefox.

## Установка

Установите локальный пакет Arch из каталога, куда вы его скачали.

```sh
sudo pacman -U ./kanso-browser-160.0.1-14-x86_64.pkg.tar.zst
```

В лаунчере Omarchy приложение называется **Kanso**. Его также можно открыть командой `kanso-browser`. Действия лаунчера открывают обычное или приватное окно. Системный браузер по умолчанию выбирается отдельно через Omarchy.

В **Settings → Appearance → Browser theme** находится переключатель **Follow the Omarchy theme**. При отключении переключателя Kanso применяет выбранную тему Firefox. Она хранится в профиле и доступна Firefox Sync. Выбранный в настройках режим оформления сайтов имеет приоритет над светлым или тёмным режимом Omarchy. Палитра, шрифт и скругление также применяются к меню браузера, настройкам, расширениям, загрузкам, паролям, библиотеке и внутренним диалогам. В разделе **Settings → Tabs and browsing → Browser layout** можно выбрать верхние или вертикальные вкладки. Боковая панель поддерживает свёрнутый вид и закреплённые вкладки. В качестве домашней страницы новой установки используется `about:newtab`. Её можно поменять в Firefox Settings.

Kanso использует собственный каталог профилей Gecko с именем `kanso`. Точный путь текущего профиля отображается на странице `about:support`. Переустановка пакета или обновление через pacman сохраняют профиль.

## Адреса .onion

Запустите Kanso из лаунчера и введите адрес `.onion`. Пакет Arch устанавливает Tor как зависимость. Kanso запускает собственный клиент Tor при первом подключении к `.onion` и закрывает его вместе с браузером. При первом подключении может понадобиться несколько секунд для соединения с сетью Tor.

Для подключения через внешний Tor можно задать его SOCKS5-порт в `browser.kanso.onion.socks_port` на странице `about:config`. Сбросьте эту настройку, чтобы вернуться к клиенту Kanso. Настройки обычных сайтов действуют как обычно.

Для сессий, в которых нужна защита от цифрового отпечатка и маршрутизация всего трафика через Tor, используйте [Tor Browser](https://support.torproject.org/tor-browser/security/using-tor-with-other-browsers/).

## Автообновление

После полного закрытия Kanso при следующем запуске браузер проверяет последний стабильный релиз на GitHub. Если вышла новая версия, он открывает вкладку с кнопкой **«Обновить и перезапустить»**. По нажатию Kanso закрывается, скачивает пакет Arch x86-64, сверяет его размер и SHA-256 и открывает прежние вкладки. Для системной установки подтвердите обновление в диалоге системы.

Если сети нет, скачивание оборвалось или подтверждение отменено, Kanso запускает установленную версию. Можно пропустить проверку для одного запуска командой `KANSO_DISABLE_AUTO_UPDATE=1 kanso-browser`.

Для публикации нового стабильного релиза создайте файл `kanso-update.json` командой `./bin/release-manifest путь-к-пакету > kanso-update.json`. Приложите его и готовый пакет к релизу с тегом `v<версия-пакета>`.

## Ручная сборка из исходников

Из распакованного каталога с исходниками запустите нужную команду.

```sh
./bin/update --check
./bin/update --build --syncdeps
./bin/update --install --syncdeps
```

Команда получает последний стабильный выпуск из [каталога Mozilla](https://product-details.mozilla.org/1.0/firefox_versions.json) и проверяет подпись архива по [ключу Mozilla Software Releases](https://blog.mozilla.org/security/2026/08/10/updated-gpg-key-for-signing-firefox-and-thunderbird-releases/). Пакеты и временные файлы сборки находятся в `${XDG_CACHE_HOME:-$HOME/.cache}/kanso-browser`. Флаг `--syncdeps` даёт makepkg возможность установить недостающие зависимости через pacman. Для этого нужна система с актуальными пакетами Arch. Воспроизводимая версия патчей закреплена на 160.0.1.

При выпуске новой версии Firefox локальную сборку нужно запустить заново. Если изменились точки интеграции или не прошла проверка, установленная версия останется на месте. Адаптируйте патчи, выполните `./bin/prepare-source` и запустите сборку снова. Для ручной сборки закреплённой версии можно импортировать `packaging/mozilla-release.gpg` в свой GPG и выполнить `makepkg --syncdeps`.

## Проверки

```sh
node --test tests/palette.test.mjs
python -m unittest discover -s tests -p test_update.py
python tests/smoke.py /usr/bin/kanso-browser
```

Интеграционная проверка запускает отдельный профиль и меняет тему в тестовом каталоге. Она проверяет идентификатор Firefox в HTTP и JavaScript, два окна, смену светлого и тёмного режима, цвет волн на открытых вкладках, смену скругления Hyprland, приоритет над активированной темой Firefox, переключатель синхронизации и поиск через выбранную систему. Для приёмки на рабочем столе переключите Gruvbox и Catppuccin Latte из меню Omarchy и проверьте открытые окна Kanso. Приложение обновляет цвета даже при замене каталога активной темы.

В каталоге `patches/` лежат изменения к исходникам Mozilla. Встроенная интеграция и новая вкладка находятся в `kanso-components/`. К проекту применяется [Mozilla Public License 2.0](https://www.mozilla.org/MPL/2.0/).
